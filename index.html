Stay inside the $200

  • Provision a 2-vCore cluster. It's the smallest HorizonDB size and costs ~$0.44/hour.
  • Run the cluster in short sessions. Delete the cluster between build sessions; storage costs a few cents per GiB per month.
  • Use the default AI models. Azure HorizonDB provisions text-embedding-3-small, gpt-5.4, and Cohere-rerank-v4.0-fast — you pay Foundry rates only for what you call.
